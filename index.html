Kuiyi Gao

University of North Carolina at Chapel Hill · B.A. Computer Science, 2027

I work on trustworthy AI — how systems behave once they leave the lab and meet real interfaces, real tools and real people. So far that has meant multimodal safety benchmarks, jailbreak attacks and the defenses against them, agent robustness under interface noise, and runtime evidence for what an agent actually did. I am moving toward the human side of it: how persona and memory drift under interaction, and what it takes to audit an agent’s behaviour after the fact.

Papers

Publications

  1. Can't See the Forest for the Trees: Benchmarking Multimodal Safety Awareness for Multimodal LLMs

    Wenxuan Wang, Xiaoyuan Liu, Kuiyi Gao, Jen-tse Huang, Youliang Yuan, Pinjia He, Shuai Wang, Zhaopeng Tu

    ACL 2025 · Main Conference anthologyarXiv

    Multimodal models miss unsafe intent when it is split across the image and the text, and refuse harmless requests for the same reason. The benchmark scores both failures separately; we then fine-tuned against it.

  2. Chain-of-Jailbreak Attack for Image Generation Models via Step by Step Editing

    Wenxuan Wang, Kuiyi Gao, Youliang Yuan, Jen-tse Huang, Qiuzhi Liu, Shuai Wang, Wenxiang Jiao, Zhaopeng Tu

    Findings of ACL 2025 anthologyarXiv

    The attack decomposes one harmful request into a chain of individually benign edits, so no single step is one a filter would refuse and the filter never sees the composition. I designed the attack methodology, ran the attack and defense experiments, and wrote the paper.

  3. GUI-agent robustness under interface noise

    Kuiyi Gao* et al. — co-first author

    under review · 2026

    Real interfaces are noisy: overlays, dynamic content, deceptive widgets. Interface noise does not only lower success rate; it also changes which action an agent takes and raises the rate of unsafe actions.

Systems

Things I built

  • Agent Skill Firewall
    A runtime egress firewall for agent skills. It scans the skill statically, then verifies intent against action against result through an HTTP proxy seeded with canaries. Each PASS / DEFER / BLOCK decision is recorded with the evidence it was derived from. Built with a four-student team at MBZUAI UGRIP 2026.
    github.com/KuiyiGao/OpenClaw-Skill-Hack
  • MemSlot — saliency-guided compression for long documents
    A frozen encoder with 32 learnable memory slots learns which spans of a contract matter before anyone asks a question; the salient spans are then rendered and compressed through an OCR model. Evaluated on CUAD against ten control arms.
    github.com/KuiyiGao/Distorted-OCR-Compression
  • Movability segmentation
    COCO-Stuff relabelled into four levels of "can this move?", with DeepLabV3 and a custom ASPP head — a perception prior for embodied safety. mIoU 0.638 at 58 FPS.
    github.com/KuiyiGao/QuickMotionDetection
