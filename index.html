Kuiyi Gao

I work on trust at the deployment boundary — the line an AI system crosses when it starts acting on real interfaces, real tools and real people.

Two things have to hold at that line: we must be able to measure what the system does once it is out there, and we must be able to stop what it should not do. I build both — benchmarks that find the failure, and runtime defenses that carry evidence for every decision they make.

§03

Systems

  • Agent Skill Firewall
    A runtime egress firewall for agent skills: static scan, then intent–action–result verification through an HTTP proxy with canaries. Every PASS / DEFER / BLOCK decision carries the evidence it was made from, so a blocked action can be re-derived after the fact. Built with a four-student team at MBZUAI UGRIP 2026.
    github.com/KuiyiGao/OpenClaw-Skill-Hack
  • MemSlot — saliency-guided compression for long documents
    A frozen encoder with 32 learnable memory slots learns question-agnostic saliency; salient spans are rendered and compressed through an OCR model. Evaluated on CUAD against ten control arms.
    github.com/KuiyiGao/Distorted-OCR-Compression
  • Movability segmentation
    DeepLabV3 with a custom ASPP head over COCO-Stuff relabelled into four movability levels — a perception prior for embodied safety. mIoU 0.638 at 58 FPS.
    github.com/KuiyiGao/QuickMotionDetection
