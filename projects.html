Text-KEN: kernel-based novelty scores for text

CUHK Summer Undergraduate Research Programme, with Prof. Farzan Farnia

Text-KEN extends the kernel entropic novelty (KEN) score from images to text. I built the pipeline that embeds two text collections and scores how novel one is relative to the other, with no classifier to train.

MemSlot: long-document retrieval and compression

Natural language processing course project, UNC

MemSlot treats long-document question answering as a retrieval and compression problem before OCR. I built the neural retriever, document rendering, pruning baselines, and evaluation notebooks.

Poetry and image variation

AI and language course project, CUHK

Images generated from Imagist poems varied less than images from Romantic poems: a CLIP-based score of 0.12 against 0.28 with FLUX.1-dev, five poems per group. I generated images with FLUX and Stable Diffusion and compared the scores in Python.

Code and data

Movability segmentation

Deep learning course project, CUHK

This project groups objects by how they can move, then predicts those classes across a scene. I adapted a semantic-segmentation model and built the data remapping, preprocessing, training, and checkpoint-inference pipeline. In the course report it reached 0.638 validation mIoU at 58 FPS.
