MemSlot: selecting text from long contracts

COMP 586 · UNC · 2026

The model uses learnable attention slots over a fixed RoBERTa encoder to assign word-importance scores. These scores guide text selection and page layout. OCR converts the rendered pages back to text for a separate question-answering model; evaluation of the full pipeline is not yet complete.

Poetry and image variation

ENGE3940 · CUHK · 2025

The course project generated multiple images from each of ten Imagist and Romantic poem excerpts using FLUX and Stable Diffusion. I analyzed saved CLIP-based scores of differences among each excerpt’s images, compared the two poetry groups, and examined how the scores relate to prompt length.

Movability segmentation

ELEG5491 · CUHK · 2025

This project uses DeepLabV3 with a custom ASPP head to group COCO-Stuff labels into four movability classes. The classes describe object categories, from fixed structures to people and vehicles, rather than measured motion.
